Description#

블로그 제작전 배포 테스트 진행중에 발생한 에러

How To Resolve#

개발자가 github 에서 프로젝트를 clone 할때 사용하는 url 에는 2종류가 있습니다.

  • HTTPS
  • SSH

~ 는 주로 SSH 를 사용하여 아래와 같이 git remote url 을 설정하여 사용합니다.

git remote origin url
origin  git@github.com-chlee-tlowac:chlee-tlowac/chlee-story.git (push)

바로 이부분에서 휴먼 에러가 발생합니다.
Docusaurus 에서는 배포를 위한 기본 명령어를 아래와 같이 제공합니다.

package.json - deploy command( default )
  "deploy":"docusaurus deploy"

~ 는 Github Page 에 배포하기 위해서 command 를 아래와 같이 수정하여 사용했습니다.
하지만, 이러한 방식은 공식문서( deprecated ) 에서 HTTPS 를 사용한다고 명시되어있습니다.

package.json - deploy command( HTTPS )
  "deploy": "GIT_USER=chlee-tlowac CURRENT_BRANCH=gp-pages docusaurus deploy"

따라서 이와 같은 이유에서 git remote -v 가 SSH 로 설정된 프로젝트에서 docusaurus deploy 를 할때 에러가 발생한것입니다.
이에 대한 해결책 또한 공식문서에 작성되어 있는데 USE_SSH=true 설정을 사용하여 문제점을 해결할 수 있습니다.

package.json - deploy command( SSH )
  "deploy": "GIT_USER=chlee-tlowac USE_SSH=true CURRENT_BRANCH=gp-pages docusaurus deploy"

사전에 오류가 났던 명령어를 수정한뒤 다시 배포를 진행한 결과 문제 없이 Github Page 에 배포된 것을 확인 할 수 있습니다.
